# Trang cá nhân — Trần Thái Hòa

Mã nguồn trang cá nhân học thuật, xây trên [Jekyll](https://jekyllrb.com/) với theme
[al-folio](https://github.com/alshedivat/al-folio), host trên GitHub Pages.

**👉 Hướng dẫn sử dụng và cập nhật nội dung: [HUONG-DAN.md](HUONG-DAN.md)**

## Cấu trúc thư mục

| Thư mục / file | Chứa gì |
| --- | --- |
| `_pages/` | Các trang chính (bản tiếng Anh) |
| `_pages/vi/` | Các trang bản tiếng Việt (`/vi/...`) |
| `_bibliography/papers.bib` | Danh mục công bố khoa học |
| `_data/grants.yml` | Đề tài nghiên cứu |
| `_data/cv.yml` | Dữ liệu trang CV (học tập, công tác, kỹ năng) |
| `_data/socials.yml` | Liên kết ORCID, Scholar, GitHub, email |
| `_data/resources.yml` | Tài liệu giảng dạy dùng chung |
| `_teachings/` | Các học phần, lịch trình và tài liệu từng buổi |
| `_projects/` | Các dự án |
| `_posts/` | Bài blog |
| `_news/` | Tin ngắn hiện ở trang chủ |
| `assets/img/` | Hình ảnh |
| `assets/pdf/` | File PDF: CV, đề cương, slide bài giảng |
| `_config.yml` | Cấu hình chung của trang |
